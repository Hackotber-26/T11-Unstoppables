# Verified Data Intake

No verified operational dataset is currently included. Keep this directory empty until each asset has documented provenance and permission.

For every incoming verified dataset, include a neighboring `SOURCE.md` containing:

- owner and original source URL or internal record identifier
- license, terms, and evidence of permission to use and redistribute
- retrieval/observation date, geographic coverage, and time range
- field mapping, transformations, exclusions, and known limitations
- validation checks and reviewer/date
- privacy assessment and confirmation that personal or precise trip-location data is excluded or appropriately protected

Do not promote the files under `synthetic/` into this directory. The supplied demo station names and coordinates are fictional local-plane values, not real stations or GPS coordinates.
